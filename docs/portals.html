Hiring portals we cannot read

41 companies · last checked 2026-11-03 · generated from the registry

These companies hire in autonomous driving, embodied AI and foundation models. Their postings are where OpenHire cannot read them: Feishu Hire, BOSS Zhipin, or a site with no list.

The jobs are real. Open the company's own careers page in a browser to see them.

Feishu's list API needs signed requests. We treat that as access control and do not work around it. OpenHire does not read, store, date or watch these pages. In an assistant, list_portals gives the same list.

To have an assistant look for you, send it this sentence with the careers page link:

Open this careers page in a browser and list the open jobs with title, city and link; no login needed, and tell me if it will not open: (paste the careers page link)

If:

1. The assistant reads only page text

2. It says the page has no jobs

Open the careers page yourself.
