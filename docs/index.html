OpenHire

一个面向 agent 的招聘协议。岗位数据全部取自雇主自己官网招聘页背后的公开接口， 每条都带核验时间与原始申请链接，可逐条复核。简历与任何个人信息永不经过服务端。

  • 岗位在架时长月报
    按雇主招聘系统里的真实发布日统计岗位挂了多久，每月更新。
  • numbers.json
    我们对外引用的每一个数字的原始出处，含口径说明与实测日期。
  • report-data.json
    月报页的全部原始数据，可自行重算。
  • 隐私说明
    三条 CI 强制的红线：PII 不过服务端、排序不可购买、雇主只为已授权结果付费。
  • 源码
    全部开源。uvx openhire@latest serve 可自行跑一遍，得到和我们一样的数。

数据有误或想更正贵司的岗位状态？ 雇主认领入口， 免费，也可以直接要求我们把贵司从索引中移除。
