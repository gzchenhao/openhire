连接向导

把 OpenHire 接进你的 AI 助手。免费，不用注册，不收简历。这页打不开时，用国内镜像。最后更新 2026-11-03。

已读不回？先看岗位还在不在。OpenHire 让 AI 助手直接从雇主自己的系统里替你找工作，简历不出你的电脑。

选你用的助手。下面只显示它的步骤。

ChatGPT（付费档）：不用装任何东西

  1. 打开 设置 → 连接器 → 高级。打开「开发者模式」。
  2. 新建连接器。名字填 OpenHire，地址填 https://openhire-vlny.onrender.com/mcp，鉴权选「无」。
  3. 开新对话。打开 OpenHire 连接器。贴入下面的「提问」。

这个地址是我们的公网主机。它收到搜索条件和匿名指纹，收不到简历，不记查询。要搜索也不出电脑，用本机方式。第一次请求可能等几十秒。

Claude 桌面版：下载一个文件，双击

  1. 在最新发布页下载 openhire-x.y.z.mcpb。
  2. 双击文件。Claude 问是否安装时，点确认。
  3. 用菜单里的 Quit 退出 Claude，再打开。
  4. 开新对话。贴入下面的「提问」。

Claude Code、Cursor、腾讯 WorkBuddy、TRAE：让它自己装

  1. 把方括号里的内容改成你的情况。
  2. 贴入下面的「装机加提问」。
  3. 助手说要重启时，重启它，再贴一次。

Cursor：也可以点 Install in Cursor。先装 uv。WorkBuddy：改完配置，退出再打开。

豆包（豆包工作）：本机起一个端口，再新建连接器

  1. 装 uv（见页尾）。
  2. 在终端里运行：
    uvx openhire@latest serve --transport streamable-http --port 8000
  3. 在豆包里打开 技能·连接器·伙伴 → 新建 → 新建自定义连接器。
  4. 传输类型选 HTTP。服务器 URL 填 http://127.0.0.1:8000/mcp。Headers 留空。保存，打开开关。
  5. 开新对话。贴入下面的「提问」。

DeepSeek：放进一个支持 MCP 的客户端

DeepSeek App 不能接 MCP。在 Cherry Studio、Chatbox、Cline、腾讯 WorkBuddy 或 TRAE 里选 DeepSeek 模型，再加 OpenHire。

  1. 装 uv（见页尾）。
  2. Cherry Studio：打开 设置 → MCP 服务器 → 添加。类型选 STDIO，命令填 uvx，参数填 openhire@latest serve。其他客户端：用「其他 / 手动配置」里的一行 JSON。
  3. 开新对话。贴入下面的「提问」。

VS Code（GitHub Copilot）：一个文件，或一键

  1. 装 uv（见页尾）。
  2. 点 Install in VS Code。或在项目里建 .vscode/mcp.json：
    { "servers": { "openhire": { "type": "stdio", "command": "uvx", "args": ["openhire@latest", "serve"] } } }
  3. 打开这个文件。点 JSON 上方的 Start。
  4. 在 Copilot Chat 里选 Agent 模式。在工具列表里勾选 openhire。
  5. 贴入下面的「提问」。

其他助手 / 手动配置

先装 uv。把这一行放进客户端的 MCP 配置：

{ "mcpServers": { "openhire": { "command": "uvx", "args": ["openhire@latest", "serve"] } } }

客户端只收网址时，填 https://openhire-vlny.onrender.com/mcp（streamable HTTP，无鉴权）。

如果：

1. 配置已保存

2. 助手看不到 openhire 的工具

在设置里启用或信任 openhire。

贴入下面的「提问」。

Connect guide

Connect OpenHire to your AI assistant. Free. No sign-up. No résumé upload. Last updated 2026-11-03.

Companies screen you with AI. Screen them back. OpenHire lets an AI assistant find jobs for you in employers' own hiring systems. Your résumé stays on your computer.

Select your assistant. The page then shows only its steps.

ChatGPT (paid plans): nothing to install

  1. Open Settings → Connectors → Advanced. Turn on Developer mode.
  2. Create a connector. Name: OpenHire. URL: https://openhire-vlny.onrender.com/mcp. Authentication: none.
  3. Start a new chat. Turn on the OpenHire connector. Paste the "ask" block below.

This URL is our public host. It gets your search filters and an anonymous fingerprint. It does not get your résumé. It keeps no query log. To keep searches on your computer, use a local option. The first request can take up to a minute.

Claude Desktop: download one file and double-click it

  1. Download openhire-x.y.z.mcpb from the latest release.
  2. Double-click the file. When Claude asks, confirm the install.
  3. Quit Claude from the menu. Open it again.
  4. Start a new chat. Paste the "ask" block below.

Claude Code, Cursor, Tencent WorkBuddy, TRAE: let it install itself

  1. Replace the text in square brackets with your details.
  2. Paste the "install and ask" block below.
  3. When the assistant asks for a restart, restart it. Paste the block again.

Cursor: you can also click Install in Cursor. Install uv first. WorkBuddy: after you change the config, quit and open it again.

豆包 Doubao: run a local port, then add a connector

  1. Install uv (see the foot of the page).
  2. In a terminal, run: 
    uvx openhire@latest serve --transport streamable-http --port 8000
  3. In Doubao, open 技能·连接器·伙伴 → 新建 → 新建自定义连接器.
  4. Transport: HTTP. Server URL: http://127.0.0.1:8000/mcp. Headers: empty. Save. Switch it on.
  5. Start a new chat. Paste the "ask" block below.

DeepSeek: inside an MCP-capable client

The DeepSeek app cannot connect to MCP. Select the DeepSeek model in Cherry Studio, Chatbox, Cline, Tencent WorkBuddy or TRAE. Then add OpenHire.

  1. Install uv (see the foot of the page).
  2. Cherry Studio: open Settings → MCP servers → Add. Type: STDIO. Command: uvx. Arguments: openhire@latest serve. Other clients: use the one-line JSON under "Other / by hand".
  3. Start a new chat. Paste the "ask" block below.

VS Code (GitHub Copilot): one file, or one click

  1. Install uv (see the foot of the page).
  2. Click Install in VS Code. Or create .vscode/mcp.json in your project:

  3. Open the file. Click Start above the JSON.
  4. In Copilot Chat, select Agent mode. In the tools list, select openhire.
