连接向导：把 OpenHire 接进你已经在用的 AI 助手

这页打不开或很慢（国内网络常见），用国内能开的同一页：openhire-vlny.onrender.com/connect。免费，不用注册，不收简历。最后更新 2026-10-28。

OpenHire 让 AI 助手直接从雇主自己的招聘系统里替你找工作，简历不出你的电脑。岗位还在不在，公司真不真，投之前先查一遍。接入只做一次；最难的就是这一次，所以这页只讲这一件事。先选你用的助手，下面只显示那一种的步骤。

ChatGPT（付费档）：不用装任何东西

  1. 设置 → 连接器 → 高级 → 打开「开发者模式」→ 新建连接器：名字 OpenHire，地址 https://openhire-vlny.onrender.com/mcp，鉴权选「无」。
  2. 开一个新对话，确认 OpenHire 连接器是打开的，把下面「提问」那段整段贴进去。

这条路连的是我们挂在公网的一个端点。它看得到你的搜索条件和一个匿名指纹，看不到简历，不记查询日志；介意的话换下面任何一种装在自己电脑上的方式，连搜索都不出你的电脑。第一次请求可能要等几十秒，免费主机在休眠。

Claude 桌面版：下载一个文件，双击

  1. 到 最新发布页 下载 openhire-x.y.z.mcpb，双击，Claude 会问是否安装，确认。不用装 Python，不用命令行。
  2. 完全退出 Claude 再打开（菜单里的 Quit，不是关窗口）。
  3. 新对话里把下面「提问」那段整段贴进去。Claude 桌面版的「+」菜单里也会多出七个现成的提示词，「求职清单」那个会按步骤带你走。

Claude Code、Cursor、腾讯 WorkBuddy、TRAE：让它自己装

这些助手能执行命令，所以装机和第一次提问可以合成一段。把下面「装机加提问」整段贴给它（方括号里的内容改成你自己的）。中间那道检查很重要：助手刚装完 MCP 这一轮往往还用不上新工具，不检查它会拿网页搜索凑结果。

Cursor 也可以一键：Install in Cursor（电脑上要先有 uv，见页尾）。WorkBuddy 改完配置要退出重开才会加载。

豆包（豆包工作）：本机起一个端口，再新建连接器

豆包的自定义连接器只收 HTTP 地址，不收命令，所以要先在自己电脑上把 OpenHire 跑起来（索引、指纹、匹配都在你电脑上，豆包只是通过本机端口调用它）。

  1. 装 uv（见页尾一行命令），然后在终端里跑：
    uvx openhire@latest serve --transport streamable-http --port 8000
  2. 豆包里：技能·连接器·伙伴 → 新建 → 新建自定义连接器：传输类型 HTTP，服务器 URL http://127.0.0.1:8000/mcp，Headers 留空，保存后打开开关。
  3. 新对话里把下面「提问」那段整段贴进去。

DeepSeek：放进一个支持 MCP 的客户端

DeepSeek 自己的 App 没有 MCP 入口。把 DeepSeek 当模型用在 Cherry Studio、Chatbox、Cline、腾讯 WorkBuddy、TRAE 这类客户端里，再给那个客户端加 OpenHire：

  1. 装 uv（见页尾一行命令）。
  2. Cherry Studio：设置 → MCP 服务器 → 添加 → 类型 STDIO，命令 uvx，参数 openhire@latest serve。其他客户端用「其他 / 手动配置」里那一行 JSON。
  3. 新对话里把下面「提问」那段整段贴进去。

VS Code（GitHub Copilot）：一个文件，或一键

  1. 装 uv（见页尾一行命令）。
  2. 一键：Install in VS Code。或者在项目里建 .vscode/mcp.json：
    { "servers": { "openhire": { "type": "stdio", "command": "uvx", "args": ["openhire@latest", "serve"] } } }
  3. 打开这个文件，点 JSON 上方的 Start；Copilot Chat 切到 Agent 模式，工具列表里勾上 openhire。
  4. 把下面「提问」那段整段贴进去。

其他助手 / 手动配置

任何支持 MCP 的客户端都认这一行（放进它的 MCP 配置，电脑上要先有 uv）：

{ "mcpServers": { "openhire": { "command": "uvx", "args": ["openhire@latest", "serve"] } } }

只收网址的客户端填 https://openhire-vlny.onrender.com/mcp（streamable HTTP，无鉴权）。改完配置有的客户端还要你在设置里手动「启用 / 信任」这个 server，工具才会出现；症状是配置明明在、助手却不知道有这些工具。装好后把下面「提问」那段整段贴进去。

Connect guide: put OpenHire into the assistant you already use

Free, no sign-up, no résumé upload. Last updated 2026-10-28.

OpenHire lets an AI assistant find jobs for you straight from employers' own hiring systems, with your résumé never leaving your computer. Is the job still open? Is the company real? Check both before you apply. Connecting is a one-time step and the hardest one, so this page is only about that. Pick your assistant first; only its steps are shown.

ChatGPT (paid plans): nothing to install

  1. Settings → Connectors → Advanced → turn on Developer mode → Create: name OpenHire, URL https://openhire-vlny.onrender.com/mcp, authentication none.
  2. Start a new chat with the connector enabled and paste the "ask" block below.

This path uses a copy of the server we run on a public host. It sees your search filters and an anonymous fingerprint, never a résumé, and keeps no query log; if you would rather have nothing leave your machine, use any of the local options. The first request after a quiet spell can take up to a minute: it is a free instance waking up.

Claude Desktop: download one file and double-click it

  1. From the latest release download openhire-x.y.z.mcpb and double-click it; Claude asks to install it. No Python, no terminal.
  2. Quit Claude fully and reopen it (Quit from the menu, not just the window).
  3. Paste the "ask" block below into a new chat. Claude Desktop's "+" menu also lists seven ready-made prompts; "Job-search checklist" walks you through the steps.

Claude Code, Cursor, Tencent WorkBuddy, TRAE: let it install itself

These assistants can run commands, so the install and the first search fit in one block. Paste the "install and ask" block below (replace what is in square brackets). The check in the middle matters: an assistant that has just added a server usually cannot use it until it restarts, and left alone it fakes the result with a web search.

Cursor also has one click: Install in Cursor (uv must be on the machine, see the foot of the page). WorkBuddy loads a changed config only after you quit and reopen it.

豆包 Doubao: run a local port, then add a connector

Doubao's custom connectors take an HTTP address, not a command, so OpenHire runs on your own machine first (index, fingerprint and matching stay there; Doubao only calls the local port).

  1. Install uv (one line at the foot of the page), then run: 
    uvx openhire@latest serve --transport streamable-http --port 8000
  2. In Doubao: 技能·连接器·伙伴 → 新建 → 新建自定义连接器: transport HTTP, server URL http://127.0.0.1:8000/mcp, no headers, save and switch it on.
  3. Paste the "ask" block below into a new chat.

DeepSeek: inside an MCP-capable client

The DeepSeek app has no MCP slot. Use DeepSeek as the model inside Cherry Studio, Chatbox, Cline, Tencent WorkBuddy or TRAE, and add OpenHire to that client:

  1. Install uv (one line at the foot of the page).
  2. Cherry Studio: Settings → MCP servers → Add → type STDIO, command uvx, arguments openhire@latest serve. Other clients take the one-line JSON under "Other / by hand".
  3. Paste the "ask" block below into a new chat.

VS Code (GitHub Copilot): one file, or one click

  1. Install uv (one line at the foot of the page).
  2. One click: Install in VS Code. Or create .vscode/mcp.json in your project:
    { "servers": { "openhire": { "type": "stdio", "command": "uvx", "args": ["openhire@latest", "serve"] } } }
  3. Open that file and click Start above the JSON; switch Copilot Chat to Agent mode and tick openhire in the tools list.
  4. Paste the "ask" block below.

Other assistants / by hand

Every MCP client takes this one line (uv must be installed first):

{ "mcpServers": { "openhire": { "command": "uvx", "args": ["openhire@latest", "serve"] } } }

A client that only takes a URL gets https://openhire-vlny.onrender.com/mcp (streamable HTTP, no authentication). Some clients also need you to enable or trust the new server in their settings before its tools appear; the symptom is a config that is clearly there and an assistant that does not know the tools. Then paste the "ask" block below.

Install and ask (for assistants that can run commands)

Install an MCP server for me: name openhire, command uvx openhire@latest serve. If uv is missing on this machine, install uv first.

Then check: can you call openhire's tools right now (search_jobs, for example)?
- If yes, go straight on to the job-search task below.
- If not (a restart or a new chat is needed to load it), stop and tell me how to restart. Do not substitute a web search or anything else. I will paste this whole block again after restarting.

Job-search task. About me: [city], looking for [role, e.g. AI product manager / perception / robotics operations], [N] years, skills [3 to 5], not interested in [what to exclude].
1. Search OpenHire for matching live postings: company, location, original posting date, days open and apply link, newest first.
2. List the postings that have been open unusually long separately, without concluding they are no longer hiring.
3. For employers it cannot find, use the portal directory to tell me where their careers pages are.
4. Register this intent as a watch; when I say "check", tell me what is new.
5. When I pick one, run the employer check on it.

My résumé stays on my machine; never send it to any server. I apply by clicking the links myself.

Foot of the page: install uv (one line)

Every local option needs uv (it provides uvx). Without it the assistant only says "server failed to start".

irm https://astral.sh/uv/install.ps1 | iex          # Windows PowerShell

Still stuck? Run uvx openhire@latest doctor in a terminal: it tells apart the three things that look identical from the chat window, uv missing, the index not downloaded yet, and a server configured but not enabled. Once connected, the next page is the job-search checklist.
