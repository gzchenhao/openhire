# 130 · 全站统一成 EarlyTip 版式（0.8.51，2026-11-01，云端会话）

## 背景

查公司页照 EarlyTip 版面规范改好后，领导问「openhire 这一页也改了吗」，并要求「举一反三，要改就一起改，他们本质上是同一个基因，放在 EarlyTip 的查公司是阉割版而已」。

## 做了什么

* **一份样式，一处定义**：新增 `src/openhire/house_style.py`，内容取自 EarlyTip 版面规范：米白底 #f6f6f0、正文 #1a1a1a、砖红 #c0392b、链接深蓝 #1a6496、细线 #e0e0d8、860px、系统中文字体 15px / 1.75、小节标题左侧 3px 红竖线、代码块与表格用白底加一种浅阴影、按钮是小圆角胶囊、不做深色模式、不加载网络字体。
* **六个页面全部套上**：github.io 首页、托管首页、连接向导、求职清单、读不到的招聘门户、给雇主。静态页由 `scripts/apply_house_style.py` 写入（重复运行结果一字不差，连接向导与求职清单的包内副本同步复制）；门户目录页和托管首页在生成时直接嵌入。
* **共同的顶部导航条**：左边 Open<span>Hire（「Hire」砖红），右边 首页 / 连接向导 / 求职清单 / 查公司 / 读不到的门户 / 给雇主，当前页是砖红胶囊。链接用相对地址，github.io 和托管端点两边都能点。
* **查公司页不加这条导航**：EarlyTip 的条件不许它出现产品名和求职清单，它保留自己只写「查公司」的导航条。这是规矩，不是遗漏。
* **手机上表格不再挤**：表格在手机宽度下每行改成上下排列，不会被压成一个字一行（规范第五节写的是左右滑动，这里改成上下排列，是因为横向滑动会把一半内容藏起来）。
* 连接向导里每个助手的卡片自带红竖线，卡片里的标题就不再画第二条。
* 文字一个字没改；连接向导两段可复制提示语与 README 一字不差的测试照旧通过。

## 防止以后走样

新增 `tests/test_house_style.py`（7 条）：每个静态页必须等于脚本生成的结果，门户页和托管首页必须嵌着同一份样式，样式里的颜色、字体、宽度、阴影必须与规范一致、不许有深色模式和网络字体。以后谁手改了某一页的样式，测试就红。

全量 1109 passed；六个页面各截了桌面与手机两张图核对过。
