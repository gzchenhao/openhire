# 078 · 具身智能雇主 JD 里的学历、论文、年限信号（公开快照 2026-10-13 的一次测量）

## 背景

领导 10-14 晚总结今年具身智能招聘的感受（企业招核心算法人才时，对名校和顶会论文的要求越来越明确，对是否应届反而不执着），要写成知乎文章。感受要数据撑，于是对公开快照里主营业务是机器人 / 具身智能的 37 家雇主的全部在架岗位做了一次 JD 文本扫描。脚本 `scripts/jd_signal_scan.py`，输入是公开快照（`openhire-index.db.gz`，2026-10-13 生成），任何人都能重跑。文章稿在私库，不进本仓库。

## 一、口径

- **雇主范围（人工判断，主营业务是机器人或具身智能）：** 国内 17 家 `unitree, galaxea, ubtrobot, dobot, jaka, mechmind, megarobo, pudutech, hairobotics, siasun, yijiahe, paxini, galbot, robotera, fftai, geekplus, keenon`；海外 20 家 `figureai, agilityrobotics, skildai, apptronik, carbonrobotics, pathrobotics, dexterity, fieldai, ambirobotics, 1x, dynarobotics, generalist, standardbots, cobot, physicalintelligence, robotec-ai, flexion-robotics, andromeda-robotics, agile-robots, palrobotics`。激光雷达、自动驾驶车队、AI 实验室不算。
- **样本：** 37 家在架岗位 1864 条，其中 1766 条带 200 字以上的 JD 文本；按标题粗分「研究 / 算法岗」318 条（标题含算法 / 研究 / research / scientist / learning / perception / 感知 / 规划 / 控制算法 / 模型等）与「其他岗」1546 条。
- **信号家族（标题加 JD，任一命中即算）：** 论文（顶会 / 论文 / 发表 / publication / CoRL / RSS / ICRA / IROS / NeurIPS / ICML / ICLR / CVPR …）；博士（博士 / PhD）；名校（985 / 211 / 双一流 / 名校 / top university …）；应届（应届 / 校招 / new grad / entry level）；年限（JD 里写的最低工作年限，如 3 年以上、5+ years）；真机（真机 / 实机 / real robot / real-world deployment / physical robot …）；前沿词（VLA / 世界模型 / 基础模型 / 大模型 / 强化学习 / 模仿学习 / sim2real …）；复现（复现 / reproduce / 开源 / open source）。
- **论文「优先 / 加分」判定：** 论文关键词前后 80 字内出现 优先 / 加分 / preferred / a plus / bonus / nice to have 之一。
- **在架天数：** 雇主自己的发布日到 2026-10-13。
- **精度抽查：** 论文家族随机 24 条命中，1 条误报（安全岗位 JD 里的「发表研究成果」）。
- 百分比取整。

## 三、读出来的东西（文章里用的就是这些）

1. 论文集中在研究 / 算法岗：全部 6%，研究岗 25%，国内研究岗 29%。
2. 国内研究岗提到论文的 JD 里 76% 写成优先 / 加分；海外只有 22%，其余写进任职要求。
3. 名校几乎不进 JD：1%。
4. 研究岗写年限的比例比其他岗低（44% 对 69%）；提到论文的研究岗里 59% 不写年限。
5. 博士：海外研究岗 40%，国内 11%。真机：海外研究岗 61%，国内 29%。
6. 没看到的：按发布年份，论文提及率 2024 / 2025 / 2026 分别 6% / 5% / 6%，平的；提到论文的岗位在架中位 132 天，不提的 130 天。

## 四、口径限制

- 量得到「JD 里写没写」，量不到「面试官看不看」。
- 关键词扫描有误报与漏报；「研究 / 算法岗」按标题粗分。
- 雇主名单是人工判断；换一种挑法百分比会动几个点。
- 一次快照；发布年份对比里老岗位有幸存者偏差。
