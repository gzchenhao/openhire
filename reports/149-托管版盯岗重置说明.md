# 149 · 托管版写明盯岗会被重置（0.8.69）

日期：2026-11-17（云端会话）

## 背景

11-17 领导在 ChatGPT 桌面版工作模式里接上托管端点，实测搜索成功（5 条与 11-16 快照逐条一致）。同时说明了一个缺口：Render 免费档没有持久硬盘，托管端点每次重新部署（每次发版）都会清空盯岗和投递记录，11-16 部署后复制计数读出为空就是这个原因。领导定：先在工具说明里写明会重置，暂不换主机。

## 做了什么

- **服务器指令（托管模式追加段）**：写明每次重新部署都会删除盯岗和投递记录、发版就会重新部署（常常一周几次）；要求助手登记盯岗前先告诉用户、建议用户记下条件以便重登；检查时找不到盯岗，要说「多半是更新重置了」，不说用户没登记过。
- **工具结果**：托管模式下 `watch_intent`、`check_watches`、`manage_watch`、`check_applications` 的结果都带 `hosted_reset_note`（中英各一句）；本机安装不带。三个工具的说明加一句「转告一次，并保留用户的条件」。
- **对外文字**：托管首页「这台主机收到什么」、隐私说明 §3、README、连接向导 ChatGPT 一节（中英）同步改为「每次发版更新都会清空」。
- 同日另推一处（不发版，随本版上托管端点）：连接向导与 README 加 ChatGPT 桌面版工作模式的接法（设置 → 插件 → 添加 → 添加 MCP 服务器，流式 HTTP；只在工作模式可用）。

## 证据

新增 `tests/test_hosted_reset_note.py` 3 条（只在托管模式出现、指令与首页写明、四个工具都挂上）。全量 1,197 通过。版本 0.8.69。
