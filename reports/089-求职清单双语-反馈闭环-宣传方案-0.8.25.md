# 089 · 求职清单中英双语、用户反馈闭环、宣传方案（0.8.24、0.8.25，2026-10-21）

## 背景

领导看了求职清单页（「每一步该做什么，谁来做，去哪里做」）后提三件事：一、在各个宣传渠道推这页；二、盯着用户反馈把内容更新；三、做成中英文双语，不是一行中文一行英文，是用户可以选择页面语言那种。另外要求两个求职者页面都带雇主认领那句（0.8.24 已做）。

## 一、双语（0.8.25）

**做法：一个网址，一页两块，右上角切换。** `docs/checklist.html` 里中文整块在前、英文整块在后，页面顶部「中文 / English」两个按钮。网址不变，收藏一次中英都在，国内地址和海外地址都是这一个文件。

- 默认语言按三层取：网址带 `?lang=en` 或 `?lang=zh` 最优先；其次是用户上次点过的选择（存在浏览器本地，不上传）；都没有就看浏览器语言，中文（含粤语）给中文，其余给英文。
- 切换时页面标题、`lang` 属性、按钮状态一起换，读屏软件也能读对。
- 浏览器关了脚本时两块都显示、按钮隐藏，内容不丢。
- 英文版链接一律写 `https://gzchenhao.github.io/openhire/checklist.html?lang=en`；英文装机 prompt 里的清单地址也带 `?lang=en`。
- 「查公司」页保持中文不动：那是 EarlyTip 线评估过的页，条件钉在测试里；英文读者在清单第 3 步能看到同一批官方网址。

**实测：** Chromium 跑六种组合（中文系统默认、英文系统默认、`?lang=en`、`?lang=zh`、点按钮切英文后刷新、点按钮切中文后刷新）全部正确，无脚本模式两块都显示。`tests/test_hosted.py` 钉住：两块都在、中文在前、两个按钮在、托管端点出的页和 `docs/` 一字不差。零破折号。847 tests。

**改清单的规矩：** 中英两块一起改，更新记录两边各记一行。

## 二、用户反馈闭环（0.8.25）

反馈从三条路进来，都落到同一个处理动作：当天改页、记更新记录、发版。

| 入口 | 怎么来 | 谁处理 |
|---|---|---|
| 页脚「告诉我们」 | GitHub 议题模板 `checklist_feedback.yml`（选哪一页、哪一步、说问题、给正确网址；明示不要写个人信息），自动打 `checklist` 标签 | 云端邮箱日检每天看一次 `checklist` 标签的议题，改页后在议题里回一句并关闭 |
| 知乎评论、私信 | 本机每日知乎日检按既有 SOP 分类上报 | 云端在上报里挑出关于清单的，同上处理 |
| 网址失效 | 月度工作流 `check-links.yml` 每月 1 日打开两页所有外链，404 / 410 才判失效并邮件通知；超时只报不红（12333.gov.cn 与 labour.gov.hk 对数据中心地址不答，和地址本身无关） | 云端收到通知即换网址 |

邮箱日检定时任务（`OpenHire 邮箱日检`）的提示词加了这一条，不用新建任务。

## 三、宣传方案

原则不变：一个读者只给一个网址，国内读者给 `openhire-vlny.onrender.com/checklist`，海外读者给 `gzchenhao.github.io/openhire/checklist.html?lang=en`；文案第一句说读者能拿到什么（免费、一页写全、官方网址给全、反诈骗三步、中英文），不说我们做了什么。

| 渠道 | 做什么 | 状态 |
|---|---|---|
| GitHub README、docs 首页、托管首页 | 清单放在「首次使用者拿到的三样」第一条，两个地址分国内外，注明中英文可切换 | 已上线（0.8.18 起，0.8.25 补双语一句） |
| MCP 服务器指令、`check_employer` 结果、提示词 | 助手对新手主动给清单地址；`check_employer` 带 `checklist_url` 与 `checklist_url_cn` | 已上线（0.8.18、0.8.19） |
| 装机 prompt | 「找工作任务」那句直接按清单带用户走（README、知乎稿、周表） | 已上线 |
| 知乎专文 | 一篇以清单为主的文章：七步各一句、反诈骗三步、官方网址表照抄页面，末尾合并版 prompt | 稿在私库 `zhihu-job-checklist-2026-10-21.md`，本机发 |
| 知乎投稿 | 文章发出后，在「入职前怎么查公司」「招聘骗局怎么识别」「找工作先做什么」这类问题下各一条不雷同的回答，每天最多 5 题 | 投稿 prompt 在同一稿末尾 |
| 每周「本周新发」 | 末尾一句清单链接 | 已有（周表模板 10-21 加） |
| X（英文） | 一条发版帖：bilingual checklist，`?lang=en` 地址 | 稿在私库 `x-post-checklist-2026-10-21.md`，本机发 |
| 领英、即刻 | 各一段，领英英文、即刻中文 | 稿在同一文件 |
| EarlyTip「查公司」入口 | 对方上线后指向查公司页，再从查公司页的第 3 步链接看不到清单（纯页，按条件不放）；清单的流量不靠它 | 等对方上线，本机待办第 15 条每晚看 |
| 目录描述（PyPI、Registry、四份插件清单） | 描述里已有「free job-search checklist」 | 已上线（0.8.18） |

全部文案由本机会话发（要领导浏览器登录态），写进本机待办第 16 条；领导不用动手。
