日期：2026-11-17（云端会话）

## 背景

`reports/150` 算过全行业的成本：瓶颈不是 token，是下载体积、雇主名单和读不了的平台；建议新行业一律不精抽。领导 11-17：「试点直接做吧，就选香港金融机构中后台。」同日领导问：零精抽试点的费用是不是由 GitHub 对公开仓库免费提供的 Actions 承担。

## 三、做了什么

1. **板的「地点范围」**（`ats/base.split_scope`）：种子行可写成 `citi.wd5/2|place=hong kong`，只收这个地点的岗位。范围是我们自己的，发给雇主系统的请求和投递链接一律用竖线前的租户。Workday 在取每条详情之前先按列表里的地点过滤，所以花旗全球约 2,000 条只多读列表、不读 2,000 次详情。香港的认法：Hong Kong、香港、HKSAR、HK、HKG、Kowloon、九龙（实测四家 Workday 的写法 `Kowloon  Hong Kong`、`Hong Kong, Cheung Kong Center`、`Hong Kong, China`、`Hong Kong Office New` 都认得）。
2. **第五个行业 `finance`**（金融 / 银行 / 保险 / 证券 / 资管 / 投行等中英词都认）：`search_jobs(sector="金融")`、盯岗键 `sector` 都能用；说明里写明「目前只有香港岗位」。
3. **零精抽写进代码**：`seed/sectors.ZERO_EXTRACTION = (finance,)`。抓取时这一行业的岗位一律只用免费规则，不管这次运行配的是哪个抽取器；每月两条付费精抽（技能、岗位族）的目标里也排除这一行业。测试钉住：给它一个付费抽取器，它一次都不会被调用。
4. **「中后台」一词展开**：`title=["中后台"]` 或 back office / middle office 会展开到合规、风控、运营、财务、会计、审计、法务、行政、人力、KYC、AML、清算等中英标题词；单写 compliance 不展开。
5. 另：网页搜索那段加领导的一句「搜得到，不等于今天还在：搜索引擎给的是它上次抓到的那一页，可能是昨天，也可能是几个月前」（连接向导中英、README、知乎稿）。

## 四、费用：谁出钱

| 环节 | 在哪里跑 | 我们付多少 |
|---|---|---|
| 每周读 11 家招聘系统、更新快照 | GitHub Actions（公开仓库免费） | 0 |
| 标题、地点、日期、职级、学历年限、签证 | 免费规则，同上 | 0 |
| 技能标签、岗位族精抽 | 不做（代码锁住） | 0 |
| 快照存放与下载 | GitHub Release、CNB 镜像（免费） | 0 |
| 托管端点 | Render 免费档 | 0 |
| 读职位描述全文、判断合不合适 | 用户自己的 AI 助手（get_job） | 0，token 花在用户那边 |

所以领导的理解是对的：试点的运行成本由 GitHub 的免费 Actions 承担，再加上免费的存储与托管，我们这边是零。真正要花的是一次性的人工：找雇主、核实招聘系统（这次子会话一趟约 5 美元的模型费，走的是领导的订阅额度，不是 DeepSeek）。
