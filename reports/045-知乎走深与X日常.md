## 一、先把「走深」定义清楚

领导要求把知乎这条唯一有效的路走深。走深不等于多发几篇，而是**建立一套可复现的筛题方法**，
否则下一次还是靠感觉挑题。已写入 `drafts/zhihu-target-pipeline.md`（私有仓库已同步）。

### 筛法（三步，可复现）

1. **取候选**：搜索 API 跑一组高意图关键词
2. **取真实数据**：问题页 API 会 403，改从页面内嵌的 `js-initialData` 取
   `followerCount / visitCount / answerCount`
3. **按「浏览 ÷ 回答数」排序**，再人工看三件事：现有高赞**有没有数据**、
   我们**能不能加一个别人没有的事实**、这题的共识我们是**附和还是反对**

## 二、打了最大的那个靶

**https://www.zhihu.com/question/379222495/answer/2085417560112099414**

选它的理由不只是浏览量最高，而是**这题的字面就是我们唯一能用实测数据回答的问题**，
而现有 104 个回答**全是个人观察和段子，没有一个数字** —— 最高赞给的「不超过 5%」没有出处。

**写法上最重要的决定：不附和。** 整条问题是「都是假的」的合唱，
而我们的数据部分**反对**这个共识（最久那批里 66% 近 30 天仍被雇主编辑过）。
再附和一遍没有价值，拿数据说「没那么糟，但坏的方式和你想的不一样」才有。

开头第一句是「**这个问题，没有人能直接回答，包括我**」，
先把「意图量不到」这件事说死，再给能量到的东西 —— 这既是诚实，也是差异化。

结尾照例把三条口径限制摊开（量不到意图、三种解释分不开、45 天阈值是自定的没有行业依据）。
