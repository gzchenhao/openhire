## Round 5 的三条用户可见缺陷，发版前一并修掉

**J1 薪资显示出现字面量 `None`**（我造成的）。
我把不可信的薪资下限置空是对的，但 CLI 直接把 `None` 插进了字符串：`USD None–50003`。
**读者会以为是雇主数据烂，而不是我们主动不发一个站不住的数。**
现在半开区间显示成「最高 50,003」或「50,003 起」。

**J4 `ohp doctor` 在已配置的机器上报「没有任何已知客户端」**。
这句话是真的，但读起来像「你没装」—— 实际是对方用的客户端不在我们的已知列表里。
现在会**列出到底查了哪几个**，并说明这个列表不等于全世界，让用的是别的客户端的人知道「这个检查看不到它」。

**J3 README 完全没有链接到两个公开数据页**。
月报页和 `numbers.json` 是外人唯一能核我们数字的地方，而只有已经知道它存在的人才找得到。已加到第一屏。

## 制度补丁：发版铁律第三条

写进 CLAUDE.md：**修好不等于发好。**
往后每次改动用户可见行为，当天走完：**PyPI → 打 tag → 建 Release → 挂 mcpb → 文案版本号同步**。
版本号一共四处，之前漏了 `mcpb/manifest.json`（它停在 0.5.1 正是 mcpb 一直是旧版的原因）。

## 另一件制度补丁：附件怎么给我

Gmail 连接器**只给附件 id、不给内容**。领导问要不要给我邮箱授权码 —— **我拒绝了**：
那是整个邮箱的读取权（银行、验证码、私人往来都在里面），为一个 5KB 附件付这个代价不成比例。
**约定改为：领导把附件下载到 `Downloads` 即可，我开工自己去读。** 已写进 CLAUDE.md 开工检查项。
