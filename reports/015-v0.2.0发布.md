## 一、背景

014 把覆盖面推到了国内北森 11 家 / 622 岗 + 海外 18 家 / 1,448 岗，但**这些只存在于 git main 和维护者本机**——线上 PyPI 还是 0.1.1，没有北森适配器，全网用户看不见。同时留着两个质量洞：

1. **CNY 月薪被年薪门槛系统性误杀**：中国 ATS 发布的是月薪（「25K-50K 元/月」），却和美元年薪共用 `salary_min/max` 两列，`--min-salary 300000` 会把一个实际年薪 30–60 万的岗位当成「三万块」直接丢掉。
2. **中文 Windows 控制台跑 `ohp extract-rebuild --help` 直接崩**：`UnicodeEncodeError: 'gbk' codec can't encode character '\xa5'`。

本单修洞，并把 0.2.0 推向全网。

**铁律（本单执行顺序即法）：** PyPI 0.2.0 未经全新环境验证可装之前，**绝不碰 Release 快照资产**——否则 0.1.1 的老用户会拉到含 `beisen` 租户的快照，增量刷新时遇到不认识的 vendor。

## 三、任务 A · CNY 薪资可比性（已完成）

### 做了什么

- `jobs` 新增 **`salary_period`**（`annual` | `monthly`）+ `db/migrate.py` 前向迁移：存量一律 `annual`，`ats_vendor='beisen'` 的公司名下改 `monthly`。实跑结果：**annual 15,694 / monthly 622**（622 = 北森岗总数，精确吻合）。
- `JobRecord.salary_period` 默认 `annual`；`BeisenClient` 落 `monthly`；`ingest` 新建与更新两条路径都写入。
- **比较时归一，存储不动**：`service._annualised()` 用 SQL `case` 在 `--min-salary` 过滤时把月薪 ×12；`annualise()` 是它的 Python 孪生。**`rank_score` 签名未改**（红线 #2 的排序纯函数未受影响）。
- `job_posting` 输出 `salary_period`；CLI 渲染加 `/月` 后缀。

### 单测（新增 17 项，`tests/test_salary_period.py`）

## 四、任务 B · 中文 Windows 体验（已完成）

### 根因比报障更宽

报障是 `--help` 崩在 `¥`(U+00A5)，但同样编不进 GBK（cp936）的还有 `哨兵` 输出符号 **`▸`(U+25B8)、`⬥`(U+2B25)** ——也就是说**正常运行时的输出也会崩**，不只是 `--help`。

### 双保险修复

1. `console.py::_harden_stdio()`：对 stdout/stderr 设 `errors="replace"`，**保留控制台原有编码**。（没有改成 UTF-8：在 cp936 控制台里写 UTF-8 字节会把所有中文变成乱码，那是更糟的「修复」。）
2. CLI 文案里的裸 `¥` 全部改成 `CNY`，让常见路径本来就不需要降级。

### 证据（`PYTHONIOENCODING=gbk`，无 traceback，exit 0）

```
$ ohp extract-rebuild --help
 Usage: ohp extract-rebuild [OPTIONS]
 Rebuild extraction with DeepSeek in resumable batches; hard-stops at the CNY ceiling.
 --ceiling  FLOAT  CNY hard stop (default from config).

$ ohp extract-role-family --help
 Usage: ohp extract-role-family [OPTIONS]
 Classify each job's role_family with DeepSeek; resumable, hard-stops at the CNY ceiling.
 --heuristic  Free title-keyword pass instead of DeepSeek; leaves unclear jobs NULL.
EXIT=0
```

顺带把 `search --role-family` 的过时 help「(v0.1: unpopulated → no-op)」改成与现实一致（014 已全量标注）。
