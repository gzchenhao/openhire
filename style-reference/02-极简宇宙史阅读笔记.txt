基本信息

一、作者：克里斯托弗'加尔法德。剑桥大学理论物理学博士，史蒂芬·霍金的亲传弟子，于2000—2006年师从霍金，从事有关黑洞信息悖论的研究。与史蒂芬·霍金及其女儿合著有儿童文学作品《乔治开启宇宙的秘密钥匙》，在全球45个国家出版发行。目前，加尔法德主要致力于向公众传播现代科学知识，并长期做客法国电视台和广播节目。

二、概述：全书只有一条公式，很合适对数学过敏的同学阅读。本书像是一个电影剧本，带领我们化身无处不在的小精灵，上天入地，穿越宇宙的过去、现在和未来；目睹基本粒子的诞生与涅灭；体验粒子在3个量子场的遨游；感受来自黑洞的死亡魅力……看完之后意犹未尽，我就忍不住读了2次。

本书主要内容

第一部分 宇宙的深度

一、化身小精灵的我们，从地球起飞，越飞越高，跳出地球以后看到了：地球——太阳系——银河系——木星群体——超星系团——临界最后散射面。这个宇宙的深度用以下几个数字进行说明：从太阳发出的光要8分20秒才能到达地球；银河系包含了3千亿颗恒星（假设恒星等于沙子，3千亿颗恒星=300个1立方米的纸箱装满的沙子，太阳是其中一粒沙子）；木星群体包含银河系在内的54个星系；地球发出的光要经历138亿年才能到达临界最后散射面

二、月亮是地球被撞击扯下的一块，月亮引起潮汐，带来全球海洋流动（而不是一潭死水），从而诞生了丰富的生命形式

三、行星（例如地球）是体积质量比较小的物体（从远到近是海王星天王星土星木星地球金星水星）

四、恒星（例如太阳）是质量非常大的物体，引力能量大，把内核的原子核融合产生更大的原子核（部分质量转化为能量也即E = mc²也即是热核聚变反应）能量向恒星外表扩张，这个力与恒星本身产生的引力而带来的向内压缩的力必须保持着一种平衡状态才能保持恒星的形状不变，否则会带来恒星的死亡（太阳预计50亿年以后死亡）

五、太阳能量向恒星外表扩张的过程会释放光与其他粒子，从而把太阳周围的一切剥夺成电子、离子（失去部分电子的原子）、原子核（失去所有电子的原子）。"电子+原子核"形成了一团炽热的混合物，这就是我们看到的太阳周围的一团火（光）

第二部分 宇宙的广度

一、引力是什么？引力为何会发生？引力来自何方？

（一）牛顿发明了微积分，用微积分计算引力轨迹。但引力来自何方以及产生的原因牛顿无法解释。水星的轨迹为何与众不同（产生漂移），牛顿也是无解

（二）爱因斯坦解决了牛顿不能回答的问题

● 首先把太空的所有东西拿走
● 剩下水星、太阳
● 然后拿走水星、太阳
● 宇宙真的什么都没有了
● 然后把太阳放回去，想象一个重球放在橡皮膜上（橡皮膜有肥皂），那么太阳会在这块橡皮膜上压出一个坑，蚂蚁或者其他什么的爬到被太阳弯曲了的坑就会掉进去。这种效果如同引力
● 月亮造成的时空弯曲，让地球表面的水落向月亮也是这个道理
● 水星，用这种弯曲产生的倾斜几何计算结果，完美地解释了水星轨道的变化
● 恒星、行星及其他东西运动时，对宇宙构造（弯曲）产生影响，所以宇宙是随时间变化而变化的，也即是有未来，有未来即意味着有过去，有开端。宇宙是有开端的
● 宇宙构造是一个（运动和变化着的）几何实体，是时间与空间的混合体，被自己包含的东西塑形
● 所有东西在任何方向上产生不可见的斜坡，是一个关于曲线与斜坡的几何学。物体质量（MASS）越大，斜坡越陡，重力场（gravitational field）越大。宇宙的斜坡互相作用，你中有我我中有你

二、我们每个人都是自己的宇宙的中心

（一）我们环顾四周会形成一个我们的视野圈，无论我们能看多广的范围，每个人看到的宇宙都有边缘（地平线），每个人看到的宇宙的广度不同，每个人的地平线不同

（二）我们每个人就是自己的宇宙视野圈的中心

（三）井底之蛙跳出井底看到的视野圈更大但不代表已经是宇宙的全部，哈勃望远镜看到的视野圈也未必是宇宙的全部。山外有山人外有人

（四）由于每个人都是自己的宇宙的中心，因此宇宙是多重的，80亿人口 有80亿个宇宙，有80亿个宇宙中心，每个人都是自己宇宙的主人

三、宇宙大爆炸

（一）眼睛看到的叫"可见光"，宇宙还有很多其他光线。光线能量从低到高：无线电波、微波、红外线、可见光、紫外线、X光、伽马射线（波长＜1mm的十亿分之一）

（二）眼睛是光的接收器，不是发射源，我们看到的都是已经发生的

（三）恒星发出的光线带有自己的信息，光携带宇宙的一切信息，投入我们的眼睛（望远镜）。我们看到的都是宇宙的过去

（四）临界最后散射面发出的光是可见的，含有各种颜色、能量、频率（被1978年诺贝尔获得者彭齐亚&威尔森检测的噪音）

（五）光波的颜色与能量取决于两峰之间的距离，经历138亿年的拉伸，这束光从靛色开始变蓝、绿、黄、橙、红，然后红外线（人眼不可见）、无线电，最后是微波（-270.42℃的微波冷光），颜色的变化证明了宇宙光波的两峰之间被不断拉长。这是一个被1948年计算预测到、在1965年被证实的"宇宙大爆炸"的证据。大爆炸发生在临界最后散射面（宇宙变透明）的38万年前

（六）光谱显示宇宙远处的颜色"红移"=>宇宙在膨胀=>离我们远去的东西在过去靠得会更近一些

四、每个人都能看到属于自己的宇宙大爆炸起点，宇宙是一个多重宇宙

第三部分 每个人都有自己的时间与速度

一、和光速相比，人类的时间是一样的，普适的

二、人类与人类相比，相对运动速度是不一样的【物体间的相对运动速度决定了不同的时间流逝——狭义相对论】举例：以99.995%光速运动的A从地球出发飞行6个月的时间=在地球上的B的600个月的时间，假如A和B是一对孪生兄弟，他们下次见面时年龄相差49.5岁

三、1971年3台原子钟坐飞机的实验证实：向东飞的原子钟变慢，向西飞的原子钟快

四、以上案例中快的A相对慢的B来说，A的时间膨胀了

（一）时间膨胀意味着A的1秒钟比B能多走更远的地方
（二）时间膨胀意味着A的1秒钟比B能多做更多的事情
（三）时间膨胀意味着A能看到B的一生，B的一生的画像在A的面前徐徐展开
（四）时间膨胀意味着A的前方的物体距离缩短例如1米变成1毫米（这是发生时间膨胀必然的结果，否则就会有超越光速的事情发生，这是不允许的）
（五）时间膨胀意味着A自己变重了（E = mc²=>m =E/c²，A不断获得加速所以能量E不断增加，C不变，因此m也即是MASS增大），在引力的作用下，A形成自己的重力场，对A周围的物体与光进行弯曲，自己越来越重，自己的钟表越走越慢

五、爱因斯坦相对论的日常应用：

（一）狭义相对论：物体间相对速度决定其时间的差异
（二）广义相对论（又称引力理论）：时空的弯曲与倾斜效应=引力（E = mc²）
（三）时空（四维）=时间（一维）+空间（三维：经度纬度海拔）
（四）"弯曲"是指物体的质量MASS对周围的物体/光产生影响，这个影响就是"倾斜"
（五）狭义相对论能帮我们充分理解物质如何工作（例如身体的原子的电子的运动情况）
（六）广义相对论能精确计算出一颗恒星外时空的形状以及行星的轨道
（七）广义相对论+狭义相对论的应用：GPS（天空中的表和地面的接收器对话，不断修正地球的车的地理位置）
（八）狭义相对论的错误应用："天上生活1日，相对地球生活已千年"，后半句正确，但是自己依然是自己的一百岁而不会活到自己的1万岁

第四部分 量子

一、眼见不一定为实，人类的感官因生存需要而进化，但人类感知到的世界并不是全部，例如原子，人类的眼睛是看不到的

（一）原子（atom），是指化学反应不可再分的基本微粒。原子在化学反应中不可分割，但在物理状态中可以分割。原子由原子核和绕核运动的电子组成。原子构成一般物质的最小单位，称为元素
（二）任何东西对半分26次，就会得到该材料的一个原子
（三）电子长得一模一样，不同原子的区别在于原子容纳的电子数量不同
（四）原子通过共享一个或几个电子结合在一起形成分子。有的分子很少例如H2O仅由3个原子构成，而人体内的DNA非常大（几十亿个原子）；分子中由电子 形成的绑定也会被打破，同时释放能量（例如吃东西领到身体暖和）
（五）电子能绑定在一起形成固体，也会被迫离开（原子核与电子的电荷之和不能为0）成为"离子"。离子总是想找到某个都弄西捆绑在一起，具有很高的活性

二、电子是基本粒子，电子通过虚光子、实光子（可见光线）与其他世界发生联系

（一）光子来自太阳内核聚变处，能被电子吞下。吞下光子的电子随机分裂出一个光子，该过程激发电子摇摆，产生热量、发光从而赋予物质颜色——以西红柿为例：
● 光子照射西红柿，除了红色以外的光子都被西红柿吸收变成热量（或其他能量）被储存
● 红光对西红柿的原子没有用被吐出来，进入我们人类的眼睛
● 我们看见了红色的西红柿

（二）冰箱与冰箱贴之间有电磁场，虚光子存在于电磁场中，虚光子排斥同种电荷，将异种电荷拉在一起。因此冰箱与冰箱贴会啪的一下贴在一起。不过中性物体（拥有相同数量的正电荷与负电荷实现中性）不在乎这些虚光子，所以中性物体不会有磁贴效应
● 虚光子不带任何电荷
● 虚光子是一种不可直接观测的光子

三、泡利不相容原理不允许两个电子在同一时间出现在同一地点。但是光子例外（激光的发明就是让完全相同的光子高度集中在一起，形成带有高能量的光束）

（一）如果一个新增的电子想加入一个已经构建完成的原子，它不得不定居到离原居民更远尚有空位的地方，或者占据某个原居民的地盘，把它踢走。这个不许同居的规则，叫泡利不相容原理
（二）泡利不相容原理解释了为何冰箱贴在冰箱门上而没有穿门而过
（三）泡利不相容原理解释了为何手能抓住书本：书封面的原子最外层的电子不给手指上原子的电子让位，手上电子也不退缩，两者保持距离，依靠人手的力量让这两者保持距离而"夹住"了书
（四）空气中的原子们不同享它们的原子所以没有绑定在一起；作为固体的人类原子们绑定在一起；空气中的原子并不阻碍人类穿过，而是挤向它们的邻居给人类让路，所以人类能通过空气。顺便说一下，这样的让路行为产生了风。这也是气体与固体的差别

四、电子和实光子是涟漪（量子涟漪），它们都存在于电磁场这个"海洋"中。宇宙到场都有类似电磁场的量子场，除了电磁场（量子场）还有其他场：相互强作用场（量子场）、弱核力场（量子场）；以及引力场（非量子场）

五、如果说牛顿能够在我们熟悉的日常生活尺度描述我们的世界、爱因斯坦的相对论适用于巨大而且能量密集的世界，那么量子理论适用于微小的世界（普朗克Max Planck世界）

（一）长度＜1万亿亿亿亿分之一米
（二）时间＜1万亿亿亿亿亿分之一米
（三）质量MASS＜1百万之二十克

第五部分 量子场

一、由三种量子场（电磁场、强相互作用场、弱核力场）所形成一团物质（例如地球），被引力聚在一起，漂浮并穿行在时空中。我们像海里的鱼，在这四个场游来游去，时间、质量、速度、距离，都在这些场纠缠在一起，场连接起了一切的一切

二、宇宙中所有粒子都是量子场（三个场）的表现，粒子与波好比海洋里的波浪，又像抛入空中的球，它们两者都是。粒子在所属的量子场诞生，例如电磁场的电子与光子、强相互作用场的胶子、弱相互作用场的中微子

三、场与场之间可以合并；合并后的场会产生新的基本粒子，例如：
（一）宇宙初期冷却之时（138亿年前）的电弱场（电磁场+弱核力场）的W和Z玻色子
（二）2012年在瑞士日内瓦唤醒的Higgs粒子属于希格斯场，希格斯场能量比电弱场能量更大，赋予电子、夸克质量。而光子与胶子没有质量所以他们能以光速运动

四、正如电子从来不会被单独创造而必须与另一个与它除了电荷之外一模一样的粒子（反电子）一同被产生一样道理，其他粒子有反粒子（反物质）
（一）有些粒子不带电荷所以它可以同时属于两个阵营，成为它自己的反面，例如光子
（二）或许在宇宙的某个地方存在一整个由反物质构成的世界
（三）粒子与自己的反物质相遇会涅灭而变成光（质量M变回能量E），医院的PET（正电子成像术）就是利用放射性衰变发生时会产生反物质，会与人体内对应的正常物质涅灭而变成伽马射线的原理，重建人体的3D模型

第六部分 引力和量子理论的糅合

一、如何理解量子的速度&位置只能测量其中一个（海森堡测不准原理）？
（一）量子很小，要测试量子的位置需要用足够短的波长
（二）波长越短能量越大，击中测量对象的冲击力越大，导致测量对象运动速度越快，因此无法测量速度
（三）如果为了准确测试测试对象的速度而减少能量即意味着波长变成长，这就测不准它的位置

二、量子的各种可能性为何没有在我们日常生活中被感知？薛定谔的既生又死的猫打开盒子看到的是活猫的时候，死猫去哪里了？
（一）答案或许存在埃弗雷特博士的博士论文中——宇宙中的一切都有量子物质构成，所以所有一切被看作是一个各种可能性存在的巨大量子波。每次作出选择的时候产生了分支（平行宇宙），死猫去了另一个一个平行宇宙
（二）当位于这里的你遭遇到什么坏消息而悲伤意味着无穷多的其他平行的你因为躲开了这个坏消息而快乐着（所以人一定要乐观啊，如果不介意这样自私的话）

三、量子状态叠加的应用：量子计算机利用量子粒子能够同时以不同状态存在这一能力实现同时"并行计算"

四、爱因斯坦的广义相对论与量子场无法相容

五、爱因斯坦的引力理论谜团之下的推论
（一）与我们见到的物质相比，银河系应该有5倍以上的质量（暗物质），否则所有的恒星都会飞走，包括太阳
（二）宇宙含有（暗能量），否则只允许物体之间相互吸引的广义相对论会让宇宙膨胀变慢而不是加速
（三）宇宙能量构成如下：暗能量72%、暗物质23%，已知物质（包括光）4.6%

六、引力+量子=量子引力理论（一个含有时间与空间本身的量子）可以回答什么问题
（一）爱因斯坦广义相对论的崩塌必然发生，时空就像一张膜，不停被跌入质量或者能量之后，密度超过某一个门槛，时空必定崩塌，这种"奇点"或许是我们宇宙诞生的起点（时间与空间都失去意义）
（二）霍金在《自然》杂志发表了"黑洞辐射"的发现：量子效应让黑洞蒸发，掉入黑洞的能量逃出来，而且剥夺了一切特征信息（除了质量）。也即是黑洞成为宇宙记忆流失处（尚未被证实）。这个被称之为"黑洞信息悖论"
（三）然而，如果我们把量子世界应用于黑洞本身，那么或许可以解决黑洞信息悖论

第七部分 纯理论——一个关于弦的理论

一、爆胀场与爆胀子，能把极大与极小混合在一起，并已被证实，但不完美

二、量子弦是指基本粒子不是以点状存在，而是一维空间的细长物体，像琴弦一样
（一）弦
● 弦分为开弦、闭合弦（引力）两种
● 一根弦能分成更小的弦，也能与别的弦构成更长的弦
● 弦用极小的视觉进入看的话，不是1维，而是11维（10维空间+时间）
● 弦的能量有2个来源：振动和缠绕
（二）弦的振动产生粒子
● 弦振动产生光子等一切粒子，不同的基本粒子是弦弹奏着不同的"音调"
● 波粒二象性：粒子的波动性由弦的振动产生
● 振动在弦上以光速向前传播
● 振动越剧烈，粒子的能量越大、质量越大

三、弦完美融合了量子力学与广义相对论：所有的物质和力，都来自同一个单元：振动的弦
（一）然而这是一个纯理论尚未被试验证实
（二）有可能它是对的，也有可能是错的。不要害怕错误而不敢大胆假设，为了找到正确，我们需要错误，这样我们才能向前进步

我的读后感

一、啃完霍金《果壳中的宇宙》再来读这本书，感觉就像降维打击，当然前提是我认真地啃过《果壳中的宇宙》

二、感慨本书作者深入浅出的解释能力，能把如此复杂的理论用简单的放电影的形式展现出来，证明了作者深厚的物理学基础，也能看得出来作者对物理学的热爱，这种热爱深深感染了我，读完这本书以后，我开始热爱仰望星空

三、量子世界是很诡异的，时不时挑战自己现有的知识体系，颠覆自己的认知，时不时会自我短路。但总体而言，量子理论确实很好地解释了微观世界，例如解释了心灵感应的量子纠缠。而且量子理论还能打破摩尔定律的魔咒，帮助人类实现更快的计算

四、爱因斯坦的相对论是伟大的，氢气球上升、油在水的上面、月亮引起的潮汐变化、导致苹果到头上的引力究竟是什么，全部都能被完美解释

五、我们每个个体能降临到这个世界，都是难得的缘分，我们不但要好好爱我们自己，更要好好爱别人。对这个世界有爱心，是我们尊重这份缘分的一个基本礼仪

六、或许逝去的灵魂在宇宙的某个地方关注着我们，我们不能枉费生命中的每个当下，应该好好修炼自己的灵魂，我们逝去以后才好意思与他们团聚

七、这个世界还有许多我们人类没有发现的物质与能量，它们一直在我们身边，等待我们去发现它的美。我们应该充实自己，放飞想象，大胆假设，谨慎求证
